## 1. Formulação Monte Carlo e Definição de Caminho

_(Slides 2–3)_

O Path Tracing é construído sobre o **Estimador de Monte Carlo**:

$$F_N = \frac{1}{N} \sum_{i=1}^{N} \frac{f(X_i)}{p(X_i)} \approx \int_D f(x)\,dx$$

onde $p(x)$ é a PDF (_probability distribution function_) utilizada para gerar as amostras $X_i$.

Um **caminho** é definido como uma sequência de raios que conecta a câmera a uma fonte de luz:

$$p_0 \rightarrow p_1 \rightarrow p_2 \rightarrow \dots \rightarrow p_n$$

- $p_0$: câmera/sensor
- $p_n$: fonte emissora de luz
- Vértices intermediários: interações com superfícies da cena

---

## 2. Contribuição de um Caminho

_(Slides 3–6)_

A radiância acumulada ao longo de um caminho é construída multiplicativamente, passo a passo:

### 2.1 Radiância da Fonte de Luz → $p_3$

_(Slide 3)_

$$L_i = \frac{L_e \cos\theta_{p_3}}{d^2 \, pdf(p_3)}$$

- $L_e$: radiância emitida pela fonte
- $d$: distância entre $p_3$ e $p_2$
- $pdf(p_3)$: densidade de probabilidade da amostragem da fonte

Essa expressão combica emissão, fator de projeção (cosseno), atenuação geométrica ($1/d^2$) e correção estatística Monte Carlo.

### 2.2 Reflexão em Superfície → $p_2$

_(Slide 4)_

$$L_i = L_i \frac{f_r(\mathbf{p}_2,\, \mathbf{w}_i,\, \mathbf{w}_o)\,\cos\theta_{p_2}}{pdf(-w_o)}$$

- $f_r$: BRDF (_Bidirectional Reflectance Distribution Function_)
- $\mathbf{w}_i$: direção incidente; $\mathbf{w}_o$: direção de saída

### 2.3 Contribuição ao Filme (câmera $p_0$)

_(Slide 5)_

$$L = L_i \left( f_r(\mathbf{p}_1,\, \mathbf{w}_i,\, \mathbf{w}_o) \cos\theta_{p_1} \right)$$

O resultado final é o produto encadeado de todos os fatores ao longo da trajetória.

---

## 3. Reaproveitamento de Sub-caminhos

_(Slide 6)_

Caminhos mais longos contêm sub-caminhos já calculados. Por exemplo, o caminho $p_0 \to p_1 \to p_2$ está contido em $p_0 \to p_1 \to p_2 \to p_3$. Essa propriedade permite reutilizar resultados intermediários, reduzindo o custo computacional total.

## 4. Algoritmo de Path Tracing com NEE

_(Slides 7–9)_

O slide 7 exibe um resultado de renderização com **64 caminhos por pixel** e profundidade máxima $d_{max} = 4$.

O pseudocódigo central (`TracePath`) introduz a estimativa explícita da **iluminação direta** — técnica conhecida como _Next Event Estimation_ (NEE):

```
TracePath(ray, scene, dmax)
  L = (0,0,0);  β = (1,1,1)
  for i = 1, dmax:
    hit = scene.Intersection(ray)
    if (!hit): break
    light = hit.GetLight()
    if (light):
      if (i == 0): return light.GetRadiance(...)
      else: break
    mat = hit.GetMaterial()
    p = hit.GetPoint();  n = hit.GetNormal()
    Le, wl = scene.GetLightRadiance(p, n)
    L += (Le * mat.BRDF()) * max(0, n·wl) * β
    wih, pdf = mat.GetSample()
    wi = HemisphereToGlobal(p, n, wih)
    β *= mat.BRDF() * max(0, n·wi) / pdf
    ray = Ray.Make(p, wi)
  return L
```

### Funções Auxiliares

_(Slide 9)_

- **`scene.SampleLight()`** — seleciona uma fonte aleatoriamente com probabilidade proporcional à potência: $lpdf = P_i / \sum_j P_j$
- **`light.GetSample(p)`** — sorteia um ponto uniformemente na superfície da fonte: $pdf = 1/A_i$
- É lançado um **raio de sombra**; se houver oclusão, $L_e = 0$

## 5. Amostragem do Hemisfério por Cosseno

_(Slides 10–11)_

Para materiais difusos (lambertianos), usa-se a distribuição cossenoidal do hemisfério:

$$\theta = \sin^{-1}\!\sqrt{\xi_1}, \qquad \phi = 2\pi\xi_2$$

Convertendo para coordenadas cartesianas:

$$x = \sqrt{\xi_1}\cos(2\pi\xi_2), \quad y = \sqrt{\xi_1}\sin(2\pi\xi_2), \quad z = \sqrt{1-\xi_1}$$

A PDF resultante é $p(\omega) = \cos\theta / \pi$.

### Mudança de Base Local → Global

_(Slide 11)_

Para converter a direção amostrada no sistema local para o sistema global da cena, constrói-se uma base ortonormal $(t, b, n)$ e aplica-se a matriz $M = [t, b, n]$:

```
HemisphereToGlobal(p, n, wih):
  t = (1,0,0); if t·n > 0.9: t = (0,1,0)
  b = normalize(n × t)
  t = b × n
  M = [t, b, n]
  return normalize(M * wih)
```

## 6. Integração de Caminhos Infinitos

_(Slides 12–15)_

A radiância total decomposta em termos de caminho:

$$L(\mathbf{p}_1 \to \mathbf{p}_0) = \underbrace{P(p_1) + P(p_2)}_{\text{Iluminação direta}} + P(p_3) + \sum_{i=4}^{\infty} P(p_i)$$

O problema é que a série é **infinita** — computacionalmente impossível de avaliar por completo.

### 6.1 Roleta Russa (_Russian Roulette_)

_(Slides 13–15)_

Técnica que permite interromper caminhos longos **sem introduzir viés**. Define-se uma probabilidade de terminação $q$ e substitui-se o restante por:

$$F' = \begin{cases} \dfrac{F - qc}{1-q} & \text{se } \xi > q \\ c & \text{caso contrário} \end{cases}$$

O valor esperado é preservado:

$$E[F'] = (1-q)\left(\frac{E[F]-qc}{1-q}\right) + qc = E[F]$$

Generalização recursiva a partir da profundidade 3 _(Slide 14)_:

$$L = P(p_1) + P(p_2) + P(p_3) + \frac{1}{1-q_3}\!\left(P(p_3) + \frac{1}{1-q_4}(P(p_4)+\cdots)\right)$$

Na prática, adota-se uma profundidade limite $k$ com $q_k = 1$.

### 6.2 Escolha de $q$

_(Slide 15)_

A probabilidade de terminação é definida **inversamente proporcional à taxa de transferência** $T$ do caminho:

- $T$ baixo → $q$ alto (caminho irrelevante, muito provável de ser encerrado)
- $T$ alto → $q$ baixo (caminho energético, continua com mais frequência)

Adota-se também um valor mínimo de $q$ para evitar recursões infinitas.

## 7. Problema da Iluminação Direta

_(Slide 16)_

Duas estratégias de amostragem apresentam limitações opostas:

| Estratégia                        | Problema                                                          | Consequência   |
| --------------------------------- | ----------------------------------------------------------------- | -------------- |
| Amostragem por ângulo sólido      | Raramente atinge uma fonte de luz                                 | Alta variância |
| Amostragem por área de superfície | Raramente coincide com direção refletida em materiais especulares | Alta variância |

A radiância direta é uma integral do produto de funções:

$$L_o = \int_\Omega f(\mathbf{p},\mathbf{w}_o,\mathbf{w}_i)\,L_i(\mathbf{p},\mathbf{w}_i)\,|\cos\theta_i|\,d\mathbf{w}_i$$

Nenhuma PDF isolada modela bem _ambos_ os fatores ao mesmo tempo.

## 8. Multiple Importance Sampling (MIS)

_(Slides 17–22)_

### 8.1 Motivação

_(Slide 17)_

Ao usar $p(x) \propto f(x)$, o termo $g(X_i)/p(X_i)$ pode tornar-se muito grande quando $g(x)$ possui picos — gerando alta variância.

### 8.2 Estimador MIS

_(Slides 18–19)_

Usa-se **duas PDFs** diferentes, $p_f(x)$ e $p_g(x)$, combinadas com funções de peso $w_f$ e $w_g$:

$$F = \frac{1}{n_f}\sum_{i=1}^{n_f} \frac{f(X_i)\,g(X_i)\,w_f(X_i)}{p_f(X_i)} + \frac{1}{n_g}\sum_{i=1}^{n_g} \frac{f(Y_i)\,g(Y_i)\,w_g(Y_i)}{p_g(Y_i)}$$

O estimador é não-viesado: $E[F] = \int f(x)\,g(x)\,dx$.

### 8.3 Por que funciona?

_(Slide 21)_

Com os pesos da heurística balanceada, o termo:

$$\frac{f(X)\,g(X)\,w_f(X)}{p_f(X)} = \frac{f(X)\,g(X)\,n_f}{n_f\,p_f(X) + n_g\,p_g(X)}$$

Como $p_g(x) \propto g(x)$, o denominador cresce quando $g$ apresenta picos — **eliminando os picos** e reduzindo a variância.

### 8.4 Heurística Balanceada

_(Slide 20)_

$$w_s(x) = \frac{n_s\,p_s(x)}{\sum_i n_i\,p_i(x)}$$

### 8.5 Heurística da Potência

_(Slide 22)_

Proposta por Eric Veach, tende a reduzir ainda mais a variância:

$$w_s(x) = \frac{(n_s\,p_s(x))^\beta}{\sum_i (n_i\,p_i(x))^\beta}, \qquad \beta = 2$$

## 9. Materiais Reflexivos Perfeitos (Espelhos)

_(Slides 23–24)_

Para espelhos ideais, apenas **uma direção** contribui para a reflexão:

$$\mathbf{w} = \mathbf{r} \quad \text{(vetor de reflexão)}, \qquad p(\mathbf{w}) = 1$$

Todas as demais direções têm contribuição nula.

A técnica de **NEE não funciona** para espelhos perfeitos _(Slide 24)_: amostrar a fonte diretamente raramente coincide com a única direção especular válida. A única forma de obter contribuição luminosa é seguir exatamente o caminho especular até a fonte. Esse é um dos fundamentos históricos para técnicas mais avançadas:

- _Bidirectional Path Tracing_ (BDPT)
- _Vertex Connection and Merging_ (VCM)
- _Metropolis Light Transport_ (MLT)
