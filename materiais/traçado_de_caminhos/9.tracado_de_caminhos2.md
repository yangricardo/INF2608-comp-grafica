# 2. O Caminho como Unidade Fundamental de Integração

## 2.1 Estimador de Monte Carlo

O Path Tracing é formulado como um problema de integração de Monte Carlo:

:contentReference[oaicite:1]{index=1}

onde:

- \(f(x)\) representa o integrando;
- \(p(x)\) é a PDF utilizada para gerar as amostras;
- \(X_i\) são amostras aleatórias. :contentReference[oaicite:2]{index=2}

No contexto de renderização, cada amostra corresponde a um **caminho de luz completo**, ligando câmera e fonte luminosa.

---

## 2.2 Definição de Caminho

Os slides definem um caminho como:

> Uma sequência de raios que conecta a câmera a uma fonte de luz. :contentReference[oaicite:3]{index=3}

Matematicamente:

\[
p_0 \rightarrow p_1 \rightarrow p_2 \rightarrow \dots \rightarrow p_n
\]

onde:

- \(p_0\): sensor/câmera;
- \(p_n\): fonte emissora;
- vértices intermediários representam interações com superfícies.

# 4. Reaproveitamento de Subcaminhos

Os slides introduzem uma observação importante:

caminhos longos contêm caminhos menores como subconjuntos. :contentReference[oaicite:9]{index=9}

Por exemplo:

\[
p_0 \rightarrow p_1 \rightarrow p_2
\]

está contido em:

\[
p_0 \rightarrow p_1 \rightarrow p_2 \rightarrow p_3
\]

Essa propriedade permite reutilizar cálculos já realizados, reduzindo significativamente o custo computacional.

# 7. Amostragem de Fontes de Luz

## 7.1 Escolha da Fonte

A função:

```cpp
scene.SampleLight()
```

seleciona uma fonte com probabilidade proporcional à potência luminosa emitida. :contentReference[oaicite:13]{index=13}

Assim:

\[
p_i=\frac{P_i}{\sum_j P_j}
\]

onde \(P_i\) representa a potência da fonte.

---

## 7.2 Amostragem de um Ponto na Fonte

Após escolher a fonte, um ponto é selecionado sobre sua superfície.

A PDF associada é:

\[
pdf=\frac1A
\]

onde \(A\) é a área emissora. :contentReference[oaicite:14]{index=14}

---

## 7.3 Teste de Visibilidade

Um raio de sombra é lançado até o ponto amostrado.

Se houver oclusão:

\[
L_e = 0
\]

Caso contrário, a contribuição luminosa é calculada. :contentReference[oaicite:15]{index=15}

Esse procedimento corresponde ao algoritmo conhecido como **Next Event Estimation (NEE)**.

---

# 8. Amostragem do Hemisfério por Cosseno

Os slides revisitam a distribuição cossenoidal utilizada para materiais difusos. :contentReference[oaicite:16]{index=16}

A parametrização utilizada é:

\[
\theta=\sin^{-1}(\sqrt{\xi_1})
\]

\[
\phi=2\pi\xi_2
\]

com:

\[
\xi_1,\xi_2\in[0,1)
\]

---

## 8.1 Conversão para Coordenadas Cartesianas

Obtém-se:

\[
x=\sqrt{\xi_1}\cos(2\pi\xi_2)
\]

\[
y=\sqrt{\xi_1}\sin(2\pi\xi_2)
\]

\[
z=\sqrt{1-\xi_1}
\]

:contentReference[oaicite:17]{index=17}

---

## 8.2 PDF Correspondente

A densidade resultante é:

\[
p(\omega)=\frac{\cos\theta}{\pi}
\]

implícita no pseudocódigo apresentado. :contentReference[oaicite:18]{index=18}

Esta distribuição é ideal para BRDFs lambertianas.

# 9. Mudança de Base Local → Global

As direções geradas no sistema local do hemisfério precisam ser convertidas para o sistema global da cena. :contentReference[oaicite:19]{index=19}

Os slides constroem uma base ortonormal:

\[
(t,b,n)
\]

onde:

- \(n\): normal da superfície;
- \(t\): vetor tangente;
- \(b\): vetor binormal.

A transformação é realizada através da matriz:

\[
M=[t\;b\;n]
\]

resultando em:

\[
\omega=M\omega_h
\]

# 10. Integração de Caminhos Infinitos

## 10.1 Expansão da Solução

A radiância é decomposta em:

\[
L=P(p*1)+P(p_2)+P(p_3)+\sum*{i=4}^{\infty}P(p_i)
\]

:contentReference[oaicite:21]{index=21}

Os primeiros termos correspondem à iluminação direta e às primeiras reflexões indiretas.

A série possui comprimento infinito. :contentReference[oaicite:22]{index=22}

Avaliar todos os termos é impossível computacionalmente.

# 11. Russian Roulette

## 11.1 Objetivo

A técnica de **Roleta Russa** permite interromper caminhos longos sem introduzir viés estatístico. :contentReference[oaicite:23]{index=23}

---

## 11.2 Formulação

Define-se uma probabilidade de término:

\[
q
\]

e substitui-se a contribuição restante por um estimador corrigido. :contentReference[oaicite:24]{index=24}

Os slides demonstram formalmente que:

\[
E[F']=E[F]
\]

ou seja:

o valor esperado permanece inalterado. :contentReference[oaicite:25]{index=25}

---

## 11.3 Generalização

A partir da profundidade 3, cada novo salto é avaliado apenas se:

\[
\xi_i>q_i
\]

caso contrário, o caminho é encerrado. :contentReference[oaicite:26]{index=26}

---

## 11.4 Escolha de q

Os slides recomendam:

\[
q \propto \frac1T
\]

onde \(T\) é a taxa de transferência de energia do caminho. :contentReference[oaicite:27]{index=27}

Logo:

- caminhos pouco importantes → alta chance de término;
- caminhos energéticos → maior probabilidade de continuação.

# 12. Problema da Iluminação Direta

A avaliação da iluminação direta apresenta dois casos extremos:

### Amostragem por ângulo sólido

Pouca probabilidade de atingir uma fonte luminosa.

### Amostragem por área

Pouca probabilidade de coincidir com a direção refletida por materiais especulares.

Ambos os casos produzem grande variância. :contentReference[oaicite:28]{index=28}

# 13. Multiple Importance Sampling (MIS)

## 13.1 Motivação

A radiância direta é uma integral do produto:

\[
\int f(x)g(x)\,dx
\]

:contentReference[oaicite:29]{index=29}

onde:

- \(f\) representa a BRDF;
- \(g\) representa a iluminação.

Nenhuma PDF isolada consegue modelar adequadamente ambas simultaneamente.

---

## 13.2 Solução

MIS utiliza duas PDFs:

\[
p_f(x)
\]

\[
p_g(x)
\]

:contentReference[oaicite:30]{index=30}

Uma associada à BRDF e outra associada à fonte luminosa.

# 15. Justificativa Matemática do MIS

Quando uma amostra é gerada segundo:

\[
p_f(x)\propto f(x)
\]

o termo:

\[
\frac{f(x)g(x)}{p_f(x)}
\]

pode tornar-se extremamente grande se \(g(x)\) apresentar um pico local. :contentReference[oaicite:35]{index=35}

Os pesos MIS introduzem no denominador contribuições de ambas as PDFs.

Consequentemente:

- reduzem picos;
- diminuem a variância;
- melhoram a convergência. :contentReference[oaicite:36]{index=36}

# 17. Materiais Reflexivos Perfeitos

Para espelhos ideais, apenas uma direção contribui para a reflexão. :contentReference[oaicite:39]{index=39}

A amostragem torna-se determinística:

\[
\omega=r
\]

onde \(r\) é o vetor de reflexão.

A PDF associada é:

\[
p(\omega)=1
\]

para a direção refletida e zero para todas as demais. :contentReference[oaicite:40]{index=40}

# 18. Iluminação Direta em Materiais Especulares

A técnica de amostragem explícita de fontes não funciona adequadamente para espelhos perfeitos. :contentReference[oaicite:41]{index=41}

O motivo é que:

- a direção correta é única;
- amostrar a fonte diretamente raramente coincide com essa direção.

Portanto, a contribuição luminosa só pode ser obtida seguindo exatamente o caminho especular até a fonte emissora. :contentReference[oaicite:42]{index=42}

Esse conceito é uma das motivações históricas para técnicas mais avançadas como:

- Bidirectional Path Tracing (BDPT);
- Vertex Connection and Merging (VCM);
- Metropolis Light Transport (MLT).

# Conclusão

Esta segunda parte do curso transforma o Path Tracing básico em um renderizador fisicamente baseado moderno. Os principais avanços apresentados são:

1. Formulação explícita da contribuição de caminhos;
2. Next Event Estimation para iluminação direta;

4. Multiple Importance Sampling para redução de variância;
5. Tratamento correto de materiais especulares.

Do ponto de vista científico, os conceitos centrais dos slides correspondem exatamente às técnicas utilizadas em renderizadores profissionais contemporâneos como PBRT, Arnold, RenderMan, Cycles, V-Ray e motores modernos de ray tracing acelerados por GPU.
