## 1. BRDF: Definição e Equação de Renderização

_[pp. 2–4]_

A **BRDF** (_Bidirectional Reflectance Distribution Function_) é o elemento central da equação de renderização, que descreve como a luz é refletida em uma superfície:

$$L_o(\mathbf{v}) = L_e(\mathbf{v}) + \int_\Omega f_r(\mathbf{v}, \mathbf{l})\, L_i(\mathbf{l})\, \cos\theta\, dw$$

Cada termo tem um papel específico:

| Termo                                             | Significado                                                    |
| ------------------------------------------------- | -------------------------------------------------------------- |
| $L_o(\mathbf{v})$                                 | Radiância saindo na direção **v**                              |
| $L_e(\mathbf{v})$                                 | Radiância **emitida** pela superfície                          |
| $f_r(\mathbf{v}, \mathbf{l})$                     | **BRDF** — razão entre radiância saindo e irradiância recebida |
| $L_i(\mathbf{l})\cos\theta\, dw = dE(\mathbf{l})$ | Irradiância vinda da direção **l**                             |

A BRDF é formalmente definida como a razão diferencial:

$$f_r(\mathbf{v}, \mathbf{l}) = \frac{dL(\mathbf{v})}{dE(\mathbf{l})}$$

---

## 2. BRDF como Função 4D e Propriedades

_[pp. 5–6]_

Cada direção no espaço hemisférico é parametrizada por dois ângulos — **zênite** ($\theta$) e **azimute** ($\phi$) — tornando a BRDF uma função de quatro variáveis:

$$f(\theta_\mathbf{v},\, \phi_\mathbf{v},\, \theta_\mathbf{l},\, \phi_\mathbf{l})$$

Qualquer BRDF fisicamente plausível deve satisfazer duas propriedades fundamentais:

- **Não negativa:** $f(\theta_\mathbf{v}, \phi_\mathbf{v}, \theta_\mathbf{l}, \phi_\mathbf{l}) > 0$
- **Recíproca** (princípio de Helmholtz):

$$f(\theta_\mathbf{v}, \phi_\mathbf{v}, \theta_\mathbf{l}, \phi_\mathbf{l}) = f(\theta_\mathbf{l}, \phi_\mathbf{l}, \theta_\mathbf{v}, \phi_\mathbf{v})$$

A reciprocidade implica que trocar as direções de visão e iluminação não altera o valor da BRDF.

## 3. Modelo de Microfaceta de Cook-Torrance

_[pp. 7–9]_

### 3.1 Motivação

_[p. 7]_

Proposto em **1981**, o modelo representa a superfície como uma **microsuperfície imaginária** composta de pequenas facetas (menores que um pixel). A modelagem é **estatística**, não geométrica, e tem como objetivo aproximar o comportamento óptico de materiais reais.

### 3.2 Parâmetros de Controle

_[pp. 8–10]_

| Parâmetro        | Domínio          | Descrição                                                                          |
| ---------------- | ---------------- | ---------------------------------------------------------------------------------- |
| **Metalicidade** | $m \in \{0, 1\}$ | Define se o material é metálico (1) ou dielétrico (0)                              |
| **Rugosidade**   | $r \in [0, 1]$   | Controla a dispersão da reflexão especular                                         |
| **Cor base**     | —                | Metais: reflexão especular colorida; não-metais: difusa colorida, especular branca |
| **Refletância**  | —                | Apenas para não-metais; controla a intensidade da reflexão especular               |

### 3.3 Equação da BRDF de Cook-Torrance

_[p. 9]_

$$f_r(\mathbf{v}, \mathbf{l}) = \underbrace{\frac{\rho_d}{\pi}}_{f_d \text{ (difusa)}} + \underbrace{\frac{F(\mathbf{v},\mathbf{h})\; D(\mathbf{h})\; G(\mathbf{l},\mathbf{v})}{4\langle\mathbf{n}\cdot\mathbf{l}\rangle\langle\mathbf{n}\cdot\mathbf{v}\rangle}}_{f_s \text{ (especular)}}$$

O **half-vector** $\mathbf{h}$ é o vetor bissetor normalizado entre a direção de visão e a de iluminação:

$$\mathbf{h} = \frac{\mathbf{v} + \mathbf{l}}{|\mathbf{v} + \mathbf{l}|}$$

A parte especular é composta por três termos independentes: $F$, $D$ e $G$, detalhados nas seções seguintes.

## 4. Termo de Refletância Fresnel — $F(\mathbf{v}, \mathbf{h})$

_[pp. 10–14]_

### 4.1 Lei de Snell e Equações de Fresnel

_[pp. 10–11]_

A **Lei de Snell** determina a direção do raio transmitido ao cruzar a interface entre dois meios:

$$\eta_1 \sin\theta_1 = \eta_2 \sin\theta_2$$

A fração de luz refletida é obtida pela combinação das componentes paralela e perpendicular da polarização:

$$F_\parallel = \frac{\eta_2\cos\theta_1 - \eta_1\cos\theta_2}{\eta_2\cos\theta_1 + \eta_1\cos\theta_2}, \qquad F_\perp = \frac{\eta_2\cos\theta_2 - \eta_1\cos\theta_1}{\eta_2\cos\theta_2 + \eta_1\cos\theta_1}$$

A fração total refletida e transmitida:

$$F = \frac{1}{2}(F_\parallel^2 + F_\perp^2), \qquad T = 1 - F$$

### 4.2 Refletância na Incidência Normal

_[p. 11]_

Para incidência perpendicular ($\theta_1 = 0$), a expressão simplifica para:

$$F_0 = \frac{(\eta_2 - \eta_1)^2}{(\eta_2 + \eta_1)^2}$$

Valores típicos de $F_0$ para materiais comuns:

| Material | Índice de Refração ($\eta$) | $F_0$  |
| -------- | --------------------------- | ------ |
| Vácuo    | 1.0                         | 0%     |
| Ar       | 1.000292                    | ≈ 0%   |
| Água     | 1.333                       | ≈ 2%   |
| Vidro    | 1.5                         | ≈ 4%   |
| Plástico | 1.5–1.58                    | 4–5%   |
| Diamante | 2.42                        | 17,24% |

### 4.3 Valores de $F_0$ para Metais

_[p. 12]_

Para metais, $F_0$ varia com o comprimento de onda — por isso é expresso como um vetor RGB. Exemplos:

| Metal   | $F_0$ (Linear, Float) |
| ------- | --------------------- |
| Titânio | (0.542, 0.497, 0.449) |
| Cromo   | (0.549, 0.556, 0.554) |
| Ferro   | (0.562, 0.565, 0.578) |
| Cobre   | (0.955, 0.638, 0.538) |
| Ouro    | (1.022, 0.782, 0.344) |
| Prata   | (0.972, 0.960, 0.915) |

### 4.4 Fórmula Original de Cook-Torrance

_[p. 13]_

No modelo original, as microfacetas são tratadas como espelhos perfeitos (reflexão apenas quando $\mathbf{n} = \mathbf{h}$). Com $\eta_1 = 1$:

$$c = \langle\mathbf{v}\cdot\mathbf{h}\rangle, \quad g = \sqrt{\eta_2^2 + c^2 - 1}$$

$$F_\text{Cook-Torrance}(\mathbf{v},\mathbf{h}) = \frac{1}{2}\left(\frac{g-c}{g+c}\right)^2\left(1 + \left(\frac{c(g+c)-1}{c(g-c)+1}\right)^2\right)$$

### 4.5 Aproximação de Schlick

_[p. 14]_

Uma alternativa computacionalmente mais eficiente, com resultados muito próximos da fórmula exata:

$$F_\text{Schlick}(\mathbf{v},\mathbf{h}) = F_0 + (1 - F_0)(1 - \langle\mathbf{v}\cdot\mathbf{h}\rangle)^5$$

A comparação para vidro ($F_0 = 0.04$) mostra que as curvas de $F_\text{Cook-Torrance}$ e $F_\text{Schlick}$ são praticamente sobrepostas em todo o intervalo de ângulos.

## 5. Função de Distribuição Normal — $D(\mathbf{h})$

_[p. 15]_

Este termo modela a **distribuição estatística das orientações das microfacetas**. Quanto maior a rugosidade, mais dispersa é a reflexão especular. O modelo predominante na literatura é o **GGX**, proposto por Walter et al. (2007):

$$D_\text{GGX}(\mathbf{h}) = \frac{\alpha^2}{\pi\left(\langle\mathbf{n}\cdot\mathbf{h}\rangle^2(\alpha^2 - 1) + 1\right)^2}$$

onde o parâmetro $\alpha$ é derivado da rugosidade $r$:

$$\alpha = r^2$$

O uso de $r^2$ (em vez de $r$ diretamente) garante uma resposta perceptualmente mais linear ao parâmetro de rugosidade.

## 6. Termo Geométrico — $G(\mathbf{l}, \mathbf{v})$

_[pp. 16–17]_

### 6.1 Motivação

_[p. 16]_

Microfacetas adjacentes podem se obstruir mutuamente de duas formas:

- **Masking (máscara):** uma microfaceta bloqueia a **visão** de outra em relação ao observador.
- **Shadowing (sombra):** uma microfaceta bloqueia a **luz incidente** sobre outra.

O termo geométrico $G$ quantifica essa **auto-oclusão**, reduzindo a contribuição especular quando os ângulos de visão ou iluminação são rasantes.

### 6.2 Fórmula de Cook-Torrance

_[p. 17]_

$$G_\text{Cook-Torrance}(\mathbf{l},\mathbf{v}) = \min\!\left(1,\; \frac{2\langle\mathbf{n}\cdot\mathbf{h}\rangle\langle\mathbf{n}\cdot\mathbf{v}\rangle}{\langle\mathbf{v}\cdot\mathbf{h}\rangle},\; \frac{2\langle\mathbf{n}\cdot\mathbf{h}\rangle\langle\mathbf{n}\cdot\mathbf{l}\rangle}{\langle\mathbf{v}\cdot\mathbf{h}\rangle}\right)$$

### 6.3 Variante Smith–Schlick

_[p. 17]_

Uma formulação mais eficiente que **separa** as contribuições de iluminação e visão:

$$G_\text{Smith}(\mathbf{l},\mathbf{v}) = G_1(\mathbf{l})\cdot G_1(\mathbf{v})$$

onde cada fator $G_1$ (visibilidade unidirecional) é calculado pela aproximação de Schlick:

$$G_{1\,\text{Schlick}}(\mathbf{v}) = \frac{\langle\mathbf{n}\cdot\mathbf{v}\rangle}{\langle\mathbf{n}\cdot\mathbf{v}\rangle(1-k)+k}, \quad k = \frac{\alpha}{2}$$

---

## 7. Resumo: Modelo Completo

_[p. 18]_

O modelo de microfaceta de Cook-Torrance combina os três termos especulares na BRDF final:

$$\boxed{f_r(\mathbf{v}, \mathbf{l}) = \frac{\rho_d}{\pi} + \frac{F_\text{Schlick}\cdot D_\text{GGX}\cdot G_\text{Smith}}{4\langle\mathbf{n}\cdot\mathbf{l}\rangle\langle\mathbf{n}\cdot\mathbf{v}\rangle}}$$

| Componente       | Modelo Adotado         | Referência          |
| ---------------- | ---------------------- | ------------------- |
| Refletância $F$  | Aproximação de Schlick | Schlick, 1994       |
| Distribuição $D$ | GGX                    | Walter et al., 2007 |
| Geométrico $G$   | Smith–Schlick          | —                   |

### Notas de Implementação

- A parte **difusa** $\rho_d / \pi$ é constante para um dado material (albedo lambertiano normalizado).
- O **half-vector** $\mathbf{h}$ é recalculado para cada par $(\mathbf{v}, \mathbf{l})$.
- Os produtos internos $\langle\cdot\rangle$ devem ser _clamped_ a zero (i.e., $\max(0, \mathbf{a}\cdot\mathbf{b})$) para evitar valores negativos.
- O parâmetro $\alpha = r^2$ é usado tanto em $D_\text{GGX}$ quanto em $G_\text{Smith}$ (via $k = \alpha/2$).
